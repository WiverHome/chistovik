# Чистовик

**Шаблоны студенческих работ по ГОСТ для Windows.** Раньше программа называлась «Конструктор шаблонов работ».

Приложение для Windows, которое создаёт Word-шаблон студенческой работы, оформленный по ГОСТ или по методичке кафедры.

Встроенные виды работ:

| Вид работы | Стандарт |
|---|---|
| Курсовая работа | ГОСТ 7.32-2017 |
| Выпускная квалификационная работа | ГОСТ 7.32-2017 |
| Реферат | ГОСТ 7.32-2017 |
| Отчёт по практике | ГОСТ 7.32-2017 |
| Контрольная работа | ГОСТ 7.32-2017 |
| Пояснительная записка (ЕСКД) | ГОСТ Р 2.105-2019 |
| Диссертация | ГОСТ Р 7.0.11-2011 |

Для **колледжей и техникумов (СПО)** — переключатель «Колледж, техникум (СПО)» на странице «Вид работы»: курсовая работа (проект) по МДК, дипломная работа (проект) с «Согласовано» и «К защите допустить», отчёт по практике по профессиональному модулю, индивидуальный проект и реферат — с титульными листами колледжа (учредитель, специальность по ФГОС СПО, преподаватель). Оформление текста — по ГОСТ 7.32-2017.

В шаблоне уже настроены поля, шрифты, автосодержание, нумерация глав, рисунков и таблиц, а также титульный лист с данными студента.
В каждом разделе стоят подсказки, что в нём писать.

## Для студентов

1. Скачайте программу из раздела **Releases** этого репозитория и установите `Chistovik-1.3.0.msi` (права администратора не нужны) или просто запустите `Chistovik.exe`. Нужна Windows 10 или 11; .NET ставить не нужно.
2. **Вид работы** — курсовая, ВКР, реферат, отчёт по практике, контрольная, пояснительная записка (ЕСКД) или диссертация. Если кафедра выдала свой профиль (.json), импортируйте его или перетащите файл в окно.
3. **Титульный лист** — заполните, что знаете. Пустые поля останутся в шаблоне подсказками в [скобках].
4. **Правила оформления** и **Структура работы** — поменяйте только то, чего требует методичка.
5. **Создать шаблон…** (Ctrl+Enter). Если установлен Word, содержание и нумерация обновятся сразу; по желанию сохранится и PDF.

Справа всё время виден лист: титульный лист, схема страницы или содержание. Всё введённое сохраняется автоматически.

### Проверить готовую работу

Раздел **«Проверка работы»** (Ctrl+5): перетащите готовый .docx — «Чистовик» сверит его с правилами выбранного вида работы и покажет ошибки оформления: поля, шрифт, интервалы, отступы, заголовки, разрывы страниц, подписи и нумерацию рисунков и таблиц, ссылки на них, список литературы (ГОСТ Р 7.0.100, 7.0.5, 7.0.108), приложения. У каждого замечания — где оно найдено и как исправить в Word. Можно сохранить копию работы с примечаниями Word прямо у проблемных абзацев; исходный файл не меняется.

### База знаний и обучение

**«База знаний»** (Ctrl+6 или F1) — какой ГОСТ нужен работе, требования ГОСТ 7.32-2017, Р 2.105-2019, Р 7.0.11-2011, Р 7.0.97-2025, устаревшие стандарты, образцы списка литературы, приёмы в Word, чек-лист нормоконтроля. При первом запуске показывается короткое обучение; повторить — «Параметры → Обучение».

### Не знаете, какой у вас ГОСТ?

Загрузите **пример работы** (.docx, .pdf; .doc, .rtf и .odt — если установлен Word) или вставьте **текст требований** из методички
или сообщения преподавателя («поля: левое — 3 см…, шрифт 14, интервал полуторный»). Кнопки — на странице «Вид работы»
и «Определить по примеру…» в «Правилах оформления»; можно просто перетащить файл в окно (Ctrl+D, Ctrl+Shift+V — из буфера).

Приложение найдёт поля, шрифт, кегль, интервал, абзацный отступ, выравнивание, нумерацию страниц, оформление заголовков
и подписей — с уверенностью и обоснованием («в 87 % абзацев», цитата из требований) — и подскажет, на какой ГОСТ это похоже
(ГОСТ 7.32-2017, Р 2.105-2019, Р 7.0.11-2011, Р 7.0.97-2025 или устаревший 7.32-2001) и чем отличается. Вы выбираете галочками, что применить; всё можно отменить.
Файл и текст обрабатываются только на вашем компьютере.

Какие ГОСТы действуют, что в них требуется и чем они отличаются — в справочнике [design/GOSTS.md](design/GOSTS.md).

## Для кафедр

Настройте правила и структуру под свою методичку и нажмите «Сохранить профиль…» или «Поделиться…».
Получится файл .json, который студенты импортируют в приложение. ФИО, группа и тема в профиль не попадают.
Формат профиля описан на примерах `src/ShablonRabot.Core/Profiles/*.json`; ключ `extends` позволяет унаследовать базовый профиль.

## Устройство проекта

| Папка | Что внутри |
|---|---|
| `src/ShablonRabot.Core` | Модель профиля, генератор .docx (OpenXML), обновление полей через Word, встроенные профили, определение правил по примеру (`Detection/`: .docx, PDF, текст требований, сравнение с ГОСТ) |
| `src/ShablonRabot.App` | Приложение WPF (.NET 8): MVVM, темы светлая/тёмная, представления |
| `src/ShablonRabot.Cli` | Консольная утилита `shablon` для сборки шаблона без интерфейса и проверки схемы |
| `installer` | Установщик MSI (WiX 5), ставится для текущего пользователя |
| `design` | Спецификация интерфейса, кликабельный макет, аудит UX/UI, справочник ГОСТов (`GOSTS.md`) |
| `prototype` | Первый прототип на Python (tkinter) |

## Сборка

```powershell
dotnet tool install --global wix --version 5.0.2
wix extension add -g WixToolset.UI.wixext/5.0.2
.\build.ps1 -Version 1.3.0
```

Результат — в папке `dist`: самодостаточный `Chistovik.exe` (.NET у пользователя не нужен) и MSI-установщик.

Консольная проверка определения правил:

```powershell
dotnet run --project src/ShablonRabot.Cli -- detect пример.docx
dotnet run --project src/ShablonRabot.Cli -- detect --text "Поля: левое — 30 мм, правое — 15 мм…"
```

Консольная проверка готовой работы (и копия с примечаниями):

```powershell
dotnet run --project src/ShablonRabot.Cli -- check работа.docx --profile kursovaya --annotate замечания.docx
```

Консольная сборка шаблона:

```powershell
dotnet run --project src/ShablonRabot.Cli -- kursovaya -o Курсовая.docx --pdf --validate
```

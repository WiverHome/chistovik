# Аудит UX/UI — «Чистовик» 1.1

Пункты 12 и 13 исправлены 21.10.2026 в версии 1.4.2.

**Главное:**
- **Данные версии 1.0 могли «пропасть».** Если папка `%APPDATA%\Chistovik` уже существовала без файла настроек, перенос не выполнялся. Программа открывалась с пустым титульным листом, хотя данные оставались в старой папке.
- **Определение ГОСТа вело не туда.** Пример распознавался как диссертация (ГОСТ Р 7.0.11), но правила применялись к выбранной курсовой. Студент получал поля диссертации внутри курсовой — с титулом, «СОДЕРЖАНИЕМ» и заголовками курсовой.
- **Новые виды работ, добавленные в 1.1, отчасти говорили языком курсовой.** У диссертации предлагалось сократить ФИО автора до инициалов, научная специальность называлась «направлением подготовки», а подсказки правил ссылались на ГОСТ 7.32.

### Как проверялось

- **Экраны.** Все четыре раздела и параметры для каждого из 7 видов работ. Окно определения ГОСТа: по тексту требований (сообщение «из мессенджера») и по файлу (`.docx` диссертации), включая применение и отмену.
- **Размеры и темы.** Светлая и тёмная тема, окно 1280×800 и минимальное 1024×680.
- **Доступность.** Поиск кнопок, флажков, полей и списков без имени для экранного диктора: на проверенных экранах таких нет.
- **Способ.** Все действия выполнялись через UI Automation, без клавиатуры и мыши; снимки сделаны PrintWindow. Перед проверкой настройки пользователя сохранены и потом восстановлены. Снимки «после» сделаны на чистых настройках, без личных данных.
- **Регрессия.** После исправлений прогнаны все 7 шаблонов (0 ошибок схемы, ГОСТ определяется верно) и определение по тексту требований.

### Чего не проверено

- **Экран «Всё готово!» установщика и установка поверх 1.0.** Их можно увидеть только при реальной установке.
- **Перенос настроек вне песочницы.** Он проверен в изолированном окружении: и сценарий «папки нет», и сценарий «папка есть, а файла настроек нет».
- **Работа с экранным диктором вживую.** Проверены только имена элементов через UI Automation.

## Что хорошо

- **Каркас.** Светлая и тёмная темы, предпросмотр листа, автосохранение и навигация работают одинаково для всех 7 видов работ. Сообщений об ошибках и записей в журнале нет.
- **Окно определения ГОСТа.** Понятно объясняет вывод: «Совпадает 7 из 7», где применяется стандарт, чем отличается. Цитирует методичку и честно предупреждает: «это сравнение с эталонами, а не проверка нормоконтроля».
- **Тексты требований «из мессенджера».** Распознаются: «отступы слева 3 см справа 1.5, сверху снизу по 2, шрифт таймс 14».
- **Доступность.** На проверенных экранах у всех элементов управления есть имена для экранного диктора, а флажок смены вида работы озвучивается вместе с пояснением.

# Какой ГОСТ нужен моей работе
@summary С чего начать, если преподаватель сказал «оформить по ГОСТу»
@glyph E82D
@tags начало гост методичка выбор вид работы

Единого «ГОСТа на курсовую» нет. Вузы берут за основу один из стандартов и дописывают свою **методичку** — требования кафедры. Если методичка и ГОСТ расходятся, нормоконтроль проверяет по методичке.

> Сначала найдите методичку кафедры. Если её нет — оформляйте по стандарту из таблицы ниже.

## Какой стандарт берут за основу

| Вид работы | Обычно оформляют по | В «Чистовике» |
|---|---|---|
| Курсовая работа, ВКР, реферат, отчёт по практике, контрольная | ГОСТ 7.32-2017 | «Курсовая работа», «ВКР», «Реферат», «Отчёт по практике», «Контрольная работа» |
| Пояснительная записка к курсовому или дипломному проекту (технические вузы) | ГОСТ Р 2.105-2019 (ЕСКД) | «Пояснительная записка (ЕСКД)» |
| Диссертация | ГОСТ Р 7.0.11-2011 | «Диссертация» |
| Курсовая, отчёт по практике, дипломная работа, индивидуальный проект в **колледже или техникуме** | ГОСТ 7.32-2017 (в технических специальностях — ЕСКД) и методичка колледжа | «Колледж, техникум (СПО)» на странице «Вид работы» — см. [статью о СПО](article:spo) |
| Заявление, служебная записка, письмо | ГОСТ Р 7.0.97-2025 | — |

Список литературы во всех работах оформляют по отдельным стандартам — см. статью [«Список литературы»](article:references).

## Если требования прислали сообщением

Часто вместо методички присылают: «поля 3 см слева, шрифт 14, интервал полуторный». Это и есть ваши правила.

- Вставьте этот текст в «Чистовик»: **Вид работы → Вставить требования…** — программа сама найдёт поля, шрифт и интервалы и подскажет, на какой ГОСТ это похоже.
- Если есть пример работы прошлых лет — **Загрузить пример…**: правила определятся по файлу.

## Если требований нет совсем

Выберите вид работы — правила по умолчанию в «Чистовике» соответствуют стандарту. Перед сдачей проверьте готовую работу: [Проверка работы](app:check).

## Заголовки — только стилями

Выделите заголовок и выберите стиль **«Заголовок 1»** (главы), **«Заголовок 2»** (параграфы), **«Заголовок 3»** (пункты). В шаблоне «Чистовика» стили уже настроены по правилам и сами нумеруются.

## Автособираемое содержание

**Ссылки → Оглавление → Автособираемое оглавление.** Обновить: правой кнопкой по содержанию → «Обновить поле» → «целиком». Перед сдачей — **Ctrl+A, затем F9**: обновятся содержание, номера рисунков и таблиц.

## Подписи и ссылки на рисунки

- **Ссылки → Вставить название → «Рисунок»** (или «Таблица») — номер обновится сам.
- Ссылка в тексте: **Ссылки → Перекрёстная ссылка → «Рисунок» → «Постоянная часть и номер»**.

## Новая страница — разрывом, а не пустыми строками

**Ctrl+Enter** — разрыв страницы. Пустые строки «поедут» при первой правке текста. Расстояние до и после заголовка задают в стиле: Абзац → Интервал перед/после.

## Мелочи, которые замечают

| Что | Как |
|---|---|
| Тире «–» между словами | Ctrl + минус на цифровой клавиатуре, или «пробел-дефис-пробел» Word заменит сам |
| Неразрывный пробел: «2025 г.», «И. И. Иванов» | Ctrl+Shift+Пробел |
| Двойные пробелы | Ctrl+H: два пробела → один, «Заменить все» |
| Номер страницы не на титуле | двойной щелчок по колонтитулу → «Особый колонтитул для первой страницы» |
| Поля страницы | Макет → Поля → Настраиваемые поля |
| Абзацный отступ | Абзац → Первая строка: Отступ 1,25 см — не пробелы и не Tab |
